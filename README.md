
# Instrukcja uruchomienia

Do uruchomienia programu potrzeba nagrania pod scieżką:
`data/videos/video.mp4`

### Windows

```bash
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python -m src.main
```

### macOS / Linux

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 -m src.main
```
